# 👑 King Jack

טקסס הולדם ובלאק ג׳ק לחברים, כאפליקציית ווב (PWA) לטלפון.
כל שחקן משחק מהטלפון שלו, והמערכת סופרת את הכסף ומחשבת בסוף הערב מי מעביר למי.

## מה יש באפליקציה
- **טקסס הולדם**: עד 10 שחקנים, כולל בליינדים, אול-אין ופוטים צדדיים.
- **בלאק ג׳ק**: הדילר יכול להיות המחשב או אחד החברים (בנק). יש דאבל וספליט.
- **כסף אמיתי או אימון**: בשולחנות אמיתיים נשמר יומן חובות וקיזוז אוטומטי. שולחנות אימון לא נספרים.
- **בוטים**: שחקני מחשב שממלאים מקומות פנויים.
- **טיפים חכמים**: אסטרטגיה בסיסית בבלאק ג׳ק, ובפוקר אחוזי סיכוי לנצח מול יחס הפוט.
- **סטטיסטיקה**: טבלת דירוג, היסטוריה אישית וסיכום של כל ערב.
- **הזמנות**: התראה באפליקציה, התראת פוש לטלפון, או קישור בוואטסאפ.
- **שפות**: עברית ואנגלית, לבחירת כל שחקן.
- **ערכות נושא**: קלאסי, קונספירציה, קריפטו ופוליטיקה.

## איך זה בנוי
- `src/engine`: חוקי המשחקים. אותו קוד רץ בשרת ובטלפון.
- `src/screens`, `src/components`: המסכים.
- `supabase/functions/game`: השרת שמחלק קלפים ומאמת כל מהלך, כדי שאי אפשר לרמות.
- `supabase/functions/register`: הרשמה עם שם וסיסמה.
- מסד הנתונים: Supabase. כל הטבלאות מתחילות ב-`game_`.

## פקודות
```bash
npm install        # התקנה ראשונה
npm run dev        # הרצה מקומית לבדיקה
npm run build      # בנייה
npm run deploy     # בנייה ופרסום ל-GitHub Pages
node scripts/sim.ts   # סימולציית אלפי ידיים: בודקת שאף ז׳טון לא נעלם
```

כדי להריץ מקומית צריך קובץ `.env.local` עם `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` ו-`VITE_VAPID_PUBLIC_KEY`. הקובץ הזה לא נשמר ב-Git.
